# Portfolio Generator

Portfolio Generator is a responsive web app that helps users build a personal portfolio in seconds. Fill out a form, choose a template, preview the result live, and export the generated portfolio as a standalone HTML file.

Live demo: https://portfolio-generator-roan.vercel.app/

## Features

- Generate portfolio websites from a simple form-based interface
- Live preview inside the app while editing content
- Choose from 4 different portfolio templates
- Add and remove projects dynamically
- Add and remove experience entries dynamically
- Upload a profile image
- Add project prototype images
- Import an existing portfolio HTML file back into the editor
- Download the generated portfolio as HTML
- Copy generated HTML code
- Load demo data for quick testing
- Built-in form validation and character limits
- Responsive UI for desktop and mobile

## Tech Stack

## How It Works

1. Enter personal information such as name, bio, skills, contact details, and links.
2. Add project and experience sections.
3. Select one of the available templates.
4. Preview the portfolio instantly.
5. Download or copy the generated HTML.

## Run Locally

This project does not require a build step or package installation.

1. Clone the repository.
2. Open the project folder.
3. Run the app with any local static server, or open `index.html` in a browser.

Example using VS Code Live Server or any static server:

```bash
# Example with Python
python -m http.server
```

Then open the local URL in your browser.
